# Tribute Page

A tribute page web project built using HTML and CSS as part of the Oasis Infobyte Web Development Internship (Level 2 - Task 2).

## Features
- Clean and structured layout dedicated to a chosen personality
- Responsive design
- Semantic HTML elements for better accessibility

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Clone or download this repository
2. Navigate to the `WebDevL2-tribute page` folder
3. Open `index.html` in your web browser
