# To-Do Web App

A to-do list web application built using HTML, CSS, and JavaScript as part of the Oasis Infobyte Web Development Internship (Level 2 - Task 3).

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Simple and intuitive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository
2. Navigate to the `WebDev-L2-To Do web app` folder
3. Open `index.html` in your web browser
