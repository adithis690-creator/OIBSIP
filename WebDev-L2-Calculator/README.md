# Calculator

A simple calculator web application built using HTML, CSS, and JavaScript as part of the Oasis Infobyte Web Development Internship (Level 2 - Task 1).

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, division
- Clear and responsive user interface
- Real-time input display
- Keyboard-friendly button layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository
2. Navigate to the `WebDev-L2-Calculator` folder
3. Open `index.html` in your web browser
