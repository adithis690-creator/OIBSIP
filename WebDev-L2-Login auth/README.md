# Login Authentication System

A login authentication system built using HTML, CSS, and JavaScript as part of the Oasis Infobyte Web Development Internship (Level 2 - Task 4).

## Features
- User login form with input validation
- Basic authentication logic
- Error handling for incorrect credentials
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository
2. Navigate to the `WebDev-L2-Login auth` folder
3. Open `index.html` in your web browser
