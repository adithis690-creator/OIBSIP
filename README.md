# OIBSIP - Oasis Infobyte Internship Projects

This repository contains all the web development tasks completed during the **Oasis Infobyte Internship Program (Level 2)**. Each task is implemented using core web technologies — HTML, CSS, and JavaScript — and is organized into its own folder.

## Tasks Completed

### Task 1: Calculator
A simple calculator web application that performs basic arithmetic operations with a clean, responsive interface.
📁 [WebDev-L2-Calculator](./WebDev-L2-Calculator)

### Task 2: Tribute Page
A tribute page dedicated to a chosen personality, built with a structured layout and semantic HTML.
📁 [WebDevL2-tribute page](./WebDevL2-tribute page)

### Task 3: To-Do Web App
A to-do list application allowing users to add, complete, and delete tasks.
📁 [WebDev-L2-To Do web app](./WebDev-L2-To Do web app)

### Task 4: Login Authentication System
A login authentication system with form validation and basic credential handling.
📁 [WebDev-L2-Login auth](./WebDev-L2-Login auth)
